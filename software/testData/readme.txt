IMF - 17/10/2008 (file names updated November 2026)

Datasets are for the seven examples used in Zychaluk, K. and Foster, D. H.
"Model-free estimation of the psychometric function", Attention, Perception,
& Psychophysics, 2009, 71(6), 1414-1425.

The data can be downloaded in three formats: Excel, MatLab, and plain text.
Each example has the same name in every format, the R package and the
MatLab package:

  01_Miranda     Example 1. Frequency of seeing
  02_Levi        Example 2. Visual detection of path deviation
  03_Carcagno    Example 3. Discrimination of pitch
  04_Xie         Example 4. Discrimination of "porthole" views of natural scenes
  05_Schofield   Example 5. Induction of a visual motion aftereffect
  06_Nascimento  Example 6. Discrimination of image approximations
  07_Baker       Example 7. Auditory detection of a gap in noise

The variables are the same for all MatLab files:

x is stimulus level
r is number of successes
m is number of trials
